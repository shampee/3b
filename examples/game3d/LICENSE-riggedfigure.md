# RiggedFigure.gltf attribution

`RiggedFigure.gltf` in this directory is a sample asset from
[KhronosGroup/glTF-Sample-Assets](https://github.com/KhronosGroup/glTF-Sample-Assets)
(the `Models/RiggedFigure/glTF-Embedded/RiggedFigure.gltf` variant),
fetched 2026-08-15. It is used unmodified.

It is the demo's stage-2 model: a skinned mesh with a named joint
hierarchy, posed by hand (`scene.3b`'s `pose-hand-wiggle`) rather than by
sampling a clip, which is what shows the skin matrices deforming the mesh
independently of any animation playback. The file does carry one
animation of its own; `main.3b` deliberately ignores it, leaving clip
playback to be demonstrated by `CesiumMan.gltf` next to it (see
[LICENSE-cesium.md](LICENSE-cesium.md)).
