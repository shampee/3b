# CesiumMan.gltf attribution

`CesiumMan.gltf` in this directory is a sample asset from
[KhronosGroup/glTF-Sample-Assets](https://github.com/KhronosGroup/glTF-Sample-Assets)
(the `Models/CesiumMan/glTF-Embedded/CesiumMan.gltf` variant), fetched
2026-07-27 to have a real skinned + animated glTF model to build
skeletal-animation clip playback (`skin.3b`'s `AnimationClip`) against.
`RiggedFigure.gltf` next to it is the stage before this one -- skinning
shown by hand-posing a joint rather than by sampling a clip (see
[LICENSE-riggedfigure.md](LICENSE-riggedfigure.md)).
