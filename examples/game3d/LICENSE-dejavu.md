# DejaVuSans.ttf attribution

`DejaVuSans.ttf` in this directory is the DejaVu Sans regular-weight
font from the [DejaVu Fonts project](https://dejavu-fonts.github.io/),
copied 2026-08-05 from this system's own `fonts-dejavu-core` package
(`/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf`) to have a real TTF
to build `text.3b`'s font-atlas baking (stbtt's `bake-font-bitmap`)
against.
